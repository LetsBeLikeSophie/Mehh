나중에 검토할 것들. 모든 판단은 기기 안에서만 한다 ([legal-notes.md](legal-notes.md)).

## 캡처를 "글자 있는 캡처 / 화면 캡처"로 나누기 (2026-10-20)

- 캡처는 대부분 글(대화, 정보, 주소)을 남기려 했거나 화면(이미지, 장면)을 남기려 한 것.
- 캡처 화면 안에서 탭 두 개로 나눠 보여주면 고르기 쉽다.
- 판별 후보 (기기 안):
  - 픽셀 계산: 배경색 비율이 높고 가로 방향 짧은 경계가 촘촘하면 글자 캡처. 128px 썸네일보다 큰 해상도가 필요할 수 있음.
  - ML Kit 텍스트 인식(한글 모델): 정확하지만 사용 통계가 Google로 감 → 고지 여부 확인 후.
- 글자 캡처는 Cortex 같은 앱으로 보내기 좋은 후보.

## 베스트만 고르기 (토너먼트, 2026-10-19)

- 후보는 연속 컷 베스트만 (거의 같은 사진만 합치고 흔들림으로는 빼지 않음).
- 4장 중 1장 고르기 → 마지막만 1:1. 남길 장수 N ≈ 사진 수 5% (최소 3, 최대 20), 조절 가능.
- 이긴 사진은 킵, 떨어진 사진은 보류함 (바로 지우지 않음).
- "A보다 B" 선택은 취향 학습 데이터로 쓴다.

## 취향 학습으로 추천 보정

- "흔들린 사진" 추천을 사용자가 자주 살리면 흔들림 추천을 줄인다 (예: 20번 중 절반 이상).

## 크레딧 (5단계) 메모 (2026-10-20)

- 회원 가입 없음. 스토어 **소모성 상품**으로 반복 구매, 잔액은 기기에만.
- 소모성 상품은 스토어가 복원해주지 않음 → 잔액 숫자만 사용자 본인 백업에 포함
  (안드로이드: dataExtractionRules에서 크레딧 파일만 include, iOS: iCloud 키-값 저장소).
  SPEC 9장의 "구매 내역으로 복원"은 이 방식으로 바꿔야 함.
- 악용 방지는 어렵지 않은 선까지만 (서버 없음 유지):
  1. 잔액을 Android Keystore 암호화로 저장 (flutter_secure_storage)
  2. Google Play 구매 서명을 앱 안 공개키로 검증
  3. 잔액은 "구매 +N / 사용 −1" 기록에 서명을 붙여 합산
- 루팅·후킹·데이터 되돌리기까지는 막지 않는다. 매출이 커지고 실제 악용이 보이면 그때 서버 검증 검토.

## 캡처 글자/화면 나눠 보기 — 보류 (2026-10-20)

- 1.0.3에서 넣었다가 1.0.5에서 뺐다. Sophie 피드백: 구별을 잘 못하고, 캡처는 그냥 하나로 묶어 공통 정리 화면에서 보는 게 낫다.
- `textScore`는 남아 있고 지금은 중복 판정(글자 많은 사진은 파일 크기까지 확인)에만 쓴다.
- 다시 하려면 판별 정확도부터 (ML Kit 텍스트 인식은 통계 전송 고지 확인 필요).

## 중복 판정 기준을 사용자가 고르기 (2026-10-20 아이디어)

- 설정 또는 중복 화면 위 칩: 엄격(파일까지 같음) / 보통(지금) / 느슨(재저장·비슷한 캡처까지)
